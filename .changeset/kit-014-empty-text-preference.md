**An empty `preferredText` selects nothing, and description text tracks are opt-in.** `preferredText={{}}`, `{ languages: undefined }` and `{ kinds: undefined }` now select no text track, exactly like an omitted `preferredText`. Previously a present-but-empty preference selected *every* track, so `preferredText={{ languages: userLangs }}` turned every language — and the audio-description text — on at once while `userLangs` was still `undefined` on first render. Only a preference that names at least one of `languages` or `kinds` selects anything. Separately, an omitted `kinds` now means every kind *except* `descriptions`: `{ languages: ['en'] }` selects the English subtitles and captions but not the English description text, which is selected only when named — `kinds: ['descriptions']`, or `{ languages: ['en'], kinds: ['descriptions'] }` for English descriptions alone. `kinds: []` and `languages: []` still mean none, and an omitted `languages` still means any language. `pickText` (`./core`) follows the same rules: `pickText(tracks)` and `pickText(tracks, {})` now return `[]`. `selectText([...ids])` is unchanged — explicit ids are always honoured, descriptions included — and multi-track text selection is unchanged. Decision 0007.
