# examples/expo-min

Minimal Expo (SDK 54) app for Fire OS. `npx create-expo-app expo-min --template blank-typescript`, then `pnpm add @moizp/vega-media-kit react-native-video`, copy `App.tsx`, and build an Android TV APK (`eas build -p android --profile preview` or `npx expo run:android`). Install with `adb connect <stick-ip> && adb install *.apk`.
